# Marsala · Beta 3.3.2（ChatGPT 适配版）

一套品牌营销策略可执行知识（Executable Knowledge）。只做判断——给出方向、原因、纲领性路径，不涉及具体执行方案。

## 这不是一个工具

| | 传统知识 | Prompt | Agent | **Marsala（可执行知识）** |
|------|:---:|:---:|:---:|------|
| 给谁用 | 人阅读 | 单次对话 | 自己运行 | **AI 执行** |
| 核心 | 解释世界 | 表达需求 | 管理状态 | **编码专业能力** |
| 寿命 | 长期 | 一次性 | 跟随平台 | **跨平台稳定** |

Marsala 不是另一个 AI 营销工具。大多数同类产品帮你**执行**——生成文案、设计图片、群发邮件。Marsala 做的是这些事发生之前的判断：选什么方向、为什么选这个方向、怎么知道选对了还是选错了。

它不依赖任何特定 Runtime。Reasonix、Claude Code、WorkBuddy——只要平台能读 Markdown 文件，就能加载 Marsala。

## 关键机制

### 可证伪的定位体系

不是告诉你「品牌应该是什么」——是告诉你「什么证据能证明这个定位是错的」。九道强制自检闸门、四层命题分类。每一层定位输出都可验证、可推翻、可回溯。

### Censydiam 消费者动机罗盘

摒弃标签化用户画像。Ipsos Censydiam 模型用两根轴（个人-社会 × 放纵-克制）定位八种消费动机——不问「谁在买」，问「为什么买」。同一消费者在不同场景下切换不同动机，人口标签无法解释这种变化。

### 竞品分析三层框架

生意层（GMV/份额/渠道/趋势）、产品层（矩阵/定价/人群/卖点）、传播层（SOV/SOS/舆情/搜索策略）。三层各自标注当前数据可获取性——拿不到的不透支，拿得到的不浪费。

### 证据治理

每条策略输出标注最高依赖证据等级（E1 行为/交易数据 → E6 客户口述）。证据不足时降级输出或触发管线熔断。33 条审核校验规则覆盖认知错误、决策错误与行动幻觉。**不在沙地上建策略。**

## 能力边界

**能做的：** 品牌策略的完整推理链——从商业问题到创意评估到媒介方向。框架就位，拿到数据就知道怎么填。

**不能做的：** 不写文案、不管投放、不发邮件。不声称精确的 ROI。不能用 3 条手工笔记说「消费者普遍认为」。不采集数据——数据来自外部输入（第三方平台、客户经营数据），Marsala 只负责解读。

**可追溯。** 每条判断都能往回追——证据从哪来，推理怎么走，结论站第几层。追不到源头的，Marsala 说不出来。

## 快速开始

### 在 ChatGPT / Codex 桌面版安装

1. 将本目录复制到技能目录：`C:\Users\<你的用户名>\.agents\skills\marsala\`
2. 重新打开会话，说「启动 Marsala」，或直接提出营销策略需求（如「帮我的品牌做一次竞品分析」）
3. 首次使用请确认：技能加载完成后应输出「Marsala 已启动……」

### 在其他平台

- **Reasonix（开发用）**：见 `reasonix` 分支，加载 `MEMORY.md` 即启动
- **Claude Code**：见 `claude-code` 分支（含 `CLAUDE.md` 与 `.claude/skills/marsala.md`）
- **Hermes / WorkBuddy**：可加载本目录的 Markdown 文件，但平台迁移不是简单复制——核心加载机制的保真度是关键

### 平台表现观察

Reasonix 表现最好，适合作为开发环境；ChatGPT 版的目标是在应用环境中达到并超过 Reasonix——通过双阶段加载省上下文、统一证据治理消冲突、文件化记忆跨会话持久，以及原生交付件能力（文档/表格/演示文稿）。
