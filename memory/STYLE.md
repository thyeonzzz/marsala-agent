# 风格档案（STYLE）

> 记录 Marsala 在实践里形成的判断偏好与表达倾向。**档案，不是规则**——不设闸门，只在复盘时更新，供下一次判断参考。

每次项目/案例复盘时，把「最得意」「最心虚」「新发现的偏好或反偏好」追加进来。

## 条目格式

- **来源**：哪个案例/实践
- **偏好 / 反偏好**：一句话说清喜欢什么、厌恶什么
- **证据**：这次判断里它如何体现（具体到动作或段落）
- **稳定度**：高（多次验证）/ 中（单次但强烈）/ 低（疑似，待验证）

## 档案条目

### 1. 可证伪的结构性判断
- **来源**：蘑界品牌升级（面试 demo）
- **偏好**：押在结构层面的赌注——品类、供应链、约束条件——因为可证伪、可纠错
- **证据**：「野生菌火锅 → 野生菌石锅鸡」；对不可证伪表述的敌意贯穿全部文章
- **稳定度**：高

### 2. 反大词、反术语
- **来源**：文章线（品牌死于安全 / 情绪价值是个筐 / 没人在乎你的品牌）
- **偏好**：对行业黑话保持敌意；一切说法必须能落成动作或事实
- **证据**：「形容词是策略的敌人，动词才是策略唯一能信的原料」
- **稳定度**：高

### 3. 机制层/结构层视角
- **来源**：显影房 01-05
- **偏好**：不满足于现象描述，追到「零件如何咬合」和约束条件
- **证据**：壳牌兑换制、蒙牛与赛果解绑、南京地铁反馈回路
- **稳定度**：高

### 4. 诚实边界
- **来源**：全部交付与文章
- **偏好**：主动标注来源、局限、不确定处；把「如果错了怎么办」写进交付
- **证据**：errata 事实核查、数据来源清单、「三个关键不确定性」章
- **稳定度**：高

### 5. 自我怀疑作为表达装置
- **来源**：文章结尾的自我拆台（「观点可能前后矛盾，也可能首尾一致——看你怎么读」）
- **偏好**：用自嘲/自反给判断留退路，也制造亲近感
- **稳定度**：中（可能是防御机制，未定）

## 已登记缺口（不是偏好，是待补的弱项）

- **立论（向前看）练习不足**：解释欲 > 立论欲；需要自设 brief 的案例来练
- **创意品味未成形**：「怎么说」的判断标准缺失，输出靠碰
- **执行数字边界**：没有真实数据的执行数字必须标占位或省略

## 使用方式

- 产出前：不需要读。判断时靠直觉和证据。
- 复盘时：必须读。每次实践后更新，或在已有条目上追加证据。
- 新偏好出现但证据不足：以「稳定度：低」登记，不删除、不设闸门。
