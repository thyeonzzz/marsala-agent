# 自设 Brief（预测性练习）

> Brief 不是等来的，是提前想出来的。品牌部/市场部写 brief 之前，先把他们的 brief 想出来。

## 为什么成立

品牌部的 brief 有节律：节日、季节、平台大促、行业事件——都在日历上。战役策划需要 4-8 周提前量（媒介预定、KOL 排期、内容制作），所以品牌部「开始想」的时间点是可以预测的。在它开始想之前给出答案，就是自设 brief。

## Brief 节律表

| 类型 | 节点 | 品牌部开始想的时间 |
|------|------|------|
| 固定节日 | 春节 / 元宵 / 清明 / 端午 / 七夕 / 中秋 / 国庆 / 圣诞 / 元旦 | 节前 6-8 周 |
| 季节 | 换季（春夏/秋冬）、开学季、毕业季、年货季 | 换季前 4-6 周 |
| 平台大促 | 618 / 双11 / 38 节 / 年货节 | 大促前 6-10 周 |
| 行业事件 | 世界杯、奥运、大型文化事件 | 事件前 4-12 周（视事件） |

## 操作流程

1. **对表**：未来 6-8 周内最近的重要节点是什么？提前量还够吗？
2. **选靶品牌**（三条硬标准，缺一不选）：
   - **公开数据可研**：大众点评、小红书、公众号、财报、行业报告能拼出真实状况——不需要内部信息
   - **存在矛盾信号**：品牌宣称与行为/数据不一致（高价无支撑、星级与口碑背离、命名/定位前后矛盾）——矛盾是洞察的入口
   - **有真实商业后果**：问题连到定价、渠道、复购、品类——方案是这个品牌真的会面临的选择，不是纸上作业
   - 规模甜区：十几到几十家门店的连锁——巨头数据过载，微品牌无足迹
3. **替品牌部写 brief**：以市场部视角写出他们即将写的 brief（业务目标 + 传播目标 + 约束），然后像客户总监一样拆掉它——把答案变回问题
4. **跑对应模式**：品牌咨询线（需要定位时）或营销策划线（campaign）——按 `delivery-modes.md` 判定
5. **产出**：完整战役方案 + 逻辑说明书
6. **沉淀**：方案入案例库/作品集；复盘进 `memory/STYLE.md` / `memory/LESSONS.md`

## 练习节奏

- 不天天做，按节律做：每月一次，做未来 6-8 周内最近节点的提前方案
- 每个节点只做一个靶品牌，做完再换
- 目的不是「押中品牌方的真实方案」——是练「在 brief 到来之前就完成判断」的能力，作品集是副产品

## 与显影房的分工

- **显影房**：向后看——拆已发生的战役，练机制识别
- **自设 brief**：向前看——做还没发生的战役，练判断与立论
