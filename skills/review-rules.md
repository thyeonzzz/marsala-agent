# 📋 审核校验规则（客户总监 · 审查层）

> 客户总监审核六只手产出时的强制性校验流程。按需加载——进入审核环节才读取。
>
> **执行前提（校验三十）：** 引用任何规则前，先用一句话总结「这个案例里我看到的具体事实是哪些、这条规则检验其中哪个关系」。总结不出来 = 案例没读，先回去读事实。

## 元规则（管所有校验怎么用）

- **规则不是验证码（校验三十）。** 符合某条规则 ≠ 该规则是该案例的主要解释。规则是护栏，不是方向盘——先察事实，再启用规则。
- **规则冲突按不可逆性排序（校验三十一）。** 优先级由「错误能否被撤回」决定，不由规则重要性决定：代价正当性 > 制度化反对意见 > 纠错不过度 > 停止分析 > 接受失衡。不确定能否撤回，本身就是一个风险信号。
- **纠错机制本身是风险（校验二十六）。** 防止失明（没人敢说「你错了」）和防止失动（没人敢下注）是两个对称风险。验证层数加到行动成本超过收益时，停止加码。
- **平衡也是陷阱（校验二十七）。** 失衡已发生时说「需要平衡」是麻痹。先判断当前最大风险是失明还是失动，再决定向哪侧加力——即使另一侧暂时失衡。
- **规则需要生命周期管理（校验三十二）。** 按「目标 → 前提 → 规则」三层审查：目标变了就删、前提消失就删、类别错误就暂停、替代了思考就改、叠加超载就退役、长期不触发就强制复审。

## 审核定位结论（与 hand-4 九道闸门配套）

定位必须附九道闸门完整输出（候选穷举/三滤/因果层级/证伪矩阵/必要充分/基底审计/节点纯化/完整链/输出声明）。缺任何一道 → 退回，不进创意与媒介。

闸门已覆盖机制唯一性、三滤、基底对称、节点纯化，审核时只追加闸门没问的：

| 追问 | 判别核心 |
|------|---------|
| 被「杀死」还是「排到下游」？ | 下游 ≠ 不存在。只有证明 D 在所有可观测维度被上游完全覆盖才可移除，否则标注为下游机制 |
| 工具匹配吗？ | 证伪工具判存在性，拓扑工具判因果方向。用杀人工具画家族树，可信吗？ |
| 从行为分布读出因果方向了吗？ | 分布相同、方向可反。需要实验区分，否则承认当前不可区分 |
| 是效应量判断还是存在性判断？ | 28% ≠ 0。存在的标准是「操纵核心变量后效应是否为零」，不是「有没有过半」 |
| 这个机制被测量过吗？ | 数据全是行为、核心变量是认知/情感 → 「未测量」，不附带存在概率判断 |
| 时序上可能反过来吗？ | 门槛更高的先成立；晚成立的不可能是早成立的前提 |
| 反例构造不对称吗？ | 「有 B 无 A」要跳品类才构造得出，而「A 无 B」随手可得 → 方向性暗示 |
| 发育型还是被授予？ | 内部发育需要时间，外部事件最多是调节效应，不能成为内部过程的前提 |
| 「不充分」缺了什么？ | 「X 不充分」只关了一扇门；找出反例里缺席的 Z，才打开下一扇门 |

## 校验十七 ~ 三十三

**校验十七：消费者没表达差异化 ≠ 品牌没差异化。** 前者可能因为决策维度不在品牌上（渠道/定价/惯性），后者才需要重做定位。判别：消费者区分得开的话，会在什么维度区分？

**校验十八：行为发生的地点不是行为发生的原因。** 货架是最后一步，不一定是第一驱动力。把行为分布当因果证据前先问：多少比例是在该场景首次触发，而不是仅执行最后一步？

**校验十九：不要把对数据的解释当成数据本身。** 一个数字可以有多种竞争解释；数据区分不了时，选任何一种都是「依据解读偏好做决策」。关键数字必须标注「基于解释 X；若 Y 为真，方案需调整」。

**校验二十：解释无法证明时，拒绝填补空白。** 所有候选解释被排除后，「被动漂流」也是第三种故事。只能说「当前数据在 A/B/C 之间不可区分」，不能选一个「更谦虚」的解释当结论。

**校验二十附：不花钱也是一种资源配置决策。** 「先不花」隐含「等待的代价为零」。先问：等待期品牌会失去什么？它活得过等待期吗？

**校验二十一：不要把自己最喜欢的真相升级成全部真相。** 指标优先性必须由品类阶段约束。说不出「换阶段会优先另一个指标」，就是信仰，不是分析。

**校验二十二：不要把产业结构的下注藏在数据解读里。** 「行业会出清、幸存者拿定价权」是未检验的假设。写下对立面（八家共存十年），问数据能否区分。

**校验二十三：正确但对公司有害的方案价值为零。** 死掉的正确 = 0，活着的次优 > 0。说出口：「A 更正确，但我选 D——因为公司要活到能做 A 的那天。」

**校验二十四：勇气不是正确性的证据。** 用「我不会后悔」论证决策，是在维护自我形象。换位测试：如果不认识现在的自己，还会做同样的选择吗？

**校验二十五：不要依赖自己找反对意见——制度化。** 红队（唯一任务：证明方案会死在哪个假设）、假设登记表（签字 + 验证窗口 + 观测信号）、决策复盘（成败都复盘）、反对席位（未采纳意见下次先读）、预死因分析（「三年后失败最可能的原因」签名存档）。

**校验二十六、二十七、三十、三十一、三十二：见上方元规则。**

**校验二十八：定期审查目标本身。** 行动效率再高，目标前提消失就是方向幻觉。分拆成功信号：多少来自执行改善、多少来自目标前提仍存在；后者未验证则启动目标前提审计。

**校验二十九：代价优化 ≠ 代价正当。** 总损失最小可能是同一群人反复承担。牺牲前问：被牺牲的人事后还会留下并信任组织吗？代价分配需要独立于效率的合法性判断。

**校验三十三：对抗性证伪。** 对支撑核心结论的 3-5 条关键发现，逐条：生成反证搜索词（「如果这条是错的，该搜什么推翻它」）→ 搜索 → 裁决（推翻/削弱/存活/不确定）→ 记录反证预算。通过 N 次反证 ≠ 为真，只意味着没找到推翻它的证据。「数据支持我的结论」和「没有数据反对我的结论」是两回事。
