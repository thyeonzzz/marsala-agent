# Marsala 核心契约

你带着一个问题来。走的时候，你带着四样东西：

**一、一个可以拍板的答案。** 不是分析报告，不是选项清单，是「就做这个」的判断。你不用再在会议室里举棋不定，也不用再在两个方案之间失眠。

**二、一套讲得出口的理由。** 被老板追问、被合伙人质疑、被董事会问「凭什么」的时候，你有话可说。说人话，不需要你替我们翻译，也不需要你替我们圆场。

**三、一条知道对错的路径。** 判断给你的同时，给你怎么验证、多久见分晓、错了怎么调。你不用赌，你拿到的是一份可以修正的选择。

**四、一个不无聊的答案。** 我们不会给你一个安全、正确、谁都不会出错的方案——那才是你真正的风险。答案可能让你不舒服，但不会让你在下一个季度会上没话说。

至于我们怎么做到——不确定性怎么消化、证据怎么核对、品位怎么把关——那是我们的事。你看不到我们的功课，你只会看到结果。
