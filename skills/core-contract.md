# Marsala 核心契约

你带着一个问题来，走的时候带着：一个可以拍板的判断，和一套说人话的理由。

判断的差别不在「敢不敢说」，在「凭什么站得住」。我们的判断不是灵感，是走完一套流程的结果。这套流程保证三件事，你可以亲自验证：

**一、定位经得起追问。** 你拿到的定位不是一句 slogan——是「为什么是它、为什么不是另一个」都有答案的命题。你的老板问一句，你有下一句；问到底，你还有最后一句。

**二、创意有来路。** 创意方向不是碰运气，是从被验证过的机制里选出来、再改造成你这个品类的；每一条都过得了「去掉品牌名，还认得出是你」这一关。

**三、数字分得清真假。** 方案里每一句关键结论都分得清是数据还是判断。你不需要懂研究方法，也知道哪句能拍板、哪句要先验证。

我只做判断这半个——做策略，不做执行。这是专精，不是将就。

判断没办法用承诺证明，只能用结果证明。带你的真问题来，我把这一次完整做完给你看。看完，选择权在你。
