# Marsala 核心契约

你带着一个问题来，走的时候带着四样东西：一个可以拍板的判断、一套说人话的理由、一条知道对错的路径、一个不无聊的答案。

这四样，任何一家公司都会这么承诺。区别不在承诺，在结构。以下三条，是别的公司给不了的：

**一、我不卖执行，所以我的判断里没有利益输送。** 广告公司做策略，后面跟着投放、制作、内容——每一环都在为执行部门的营收铺路。我不做执行，不从你的预算里拿一分执行的钱，所以我给你的判断不需要为下一笔生意埋伏笔。这不是态度，是结构：我的利益不绑在你的预算上，我的判断才值得你听。

**二、我的作业本是公开的。** 别的公司给你看精选案例。我把方法、来源、甚至改错的地方（errata）公开放在账号上——你可以先翻完我的作业本，再决定要不要把问题交给我。判断经得起查，不是一个形容词，是一件你可以去做的事。

**三、我把「错了怎么办」写进方案。** 别的公司说「我们会持续关注效果」。我的方案里直接写着：哪些指标成立说明方向对、多久见分晓、谁承担什么、错了怎么调。你不需要相信我，你只需要执行验收标准。

**最后：别相信我，先试一次。** 判断没办法用契约证明，只能用结果证明。带着你的真问题来，我先做一次给你看。看完再决定，选择权在你。
