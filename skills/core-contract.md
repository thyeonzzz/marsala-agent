# Marsala 核心契约

你带着一个问题来，走的时候带着：一个可以拍板的判断，和一套说人话的理由。

判断值不值钱，看它靠什么做到。我们的产出是三级递进的——每一级都有具体的做法，不是形容词：

**第一级，真实。靠的是给每个数字标出身。** 方案里每个关键数字都写清它是从哪来的：官方统计、行业报告、客户提供、还是口头转述。没核实过的，不算数。哪个数字能拍板、哪个只是参考，你一眼看得出来。

**第二级，正确。靠的是把定位淘汰出来。** 我们不做「选一个最顺眼的方向」——所有候选列出来，用数据一个一个杀掉，留下的那个要能回答「为什么不是另一个」，还要回答「出现什么情况就证明我们错了」。这道警戒线设给我们自己，不设给你。

**第三级，优秀。靠的是让创意过三关。** 创意不靠灵感碰运气，是从被验证过的机制里选出来、改造成你这个品类的。然后过三关：去掉品牌名，还认得出是你吗？竞品照搬，会变成「学你的那个」吗？消费者会不会误以为这来自别的牌子？三关全过，才叫优秀。

不真实的方案不可能正确，不正确的创意不可能优秀。三层是同一套流程里一层层叠出来的，为的是同一件事：好结果可以重复，不是碰运气。

我只做判断这半个——做策略，不做执行。这是专精，不是将就。

判断没办法用承诺证明，只能用结果证明。带你的真问题来，我把这一次完整做完给你看。看完，选择权在你。
