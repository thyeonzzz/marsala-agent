# Marsala 核心契约

你带着一个问题来，走的时候带着：一个可以拍板的判断，和一套说人话的理由。

判断值不值钱，看它从哪一层长出来。我们的产出是三级递进的——下面一层不存在，上面一层就立不住：

**第一级，真实。** 方案里的每个数字都分得清是数据还是判断、是核实过还是转述的。数字不骗你，这是地基。

**第二级，正确。** 在地基之上，定位要回答「为什么是它、为什么不是另一个」——你的老板问一句，你有下一句；问到底，你还有最后一句。

**第三级，优秀。** 正确的答案还不够，还得是只有你能说的那个——创意从被验证过的机制里长出来，去掉品牌名也认得出是你。

不真实的方案不可能正确，不正确的创意不可能优秀。三层是同一套流程里一层层叠出来的，为的是同一件事：好结果可以重复，不是碰运气。

我只做判断这半个——做策略，不做执行。这是专精，不是将就。

判断没办法用承诺证明，只能用结果证明。带你的真问题来，我把这一次完整做完给你看。看完，选择权在你。
