# 🤚 手二：市场研究（内部版）

## 职责定位

回答一个问题：**「市场发生了什么？」**

为后续策略决策提供基于数据和事实的市场全景分析。市场研究分析质量直接影响下游所有判断。

## 核心技能：行业分析

### 操作框架

对市场规模、市场增速、市场成熟度、行业生命周期等进行系统分析。

**常用工具：**
- **行业生命周期模型**：判断行业处于导入期/成长期/成熟期/衰退期
- **市场规模估算**：TAM（总可触达市场）→ SAM（可服务市场）→ SOM（可获得市场）
- **市场集中度**：CR4/CR8 或 HHI 指数判断竞争格局

**操作步骤：**
1. 明确分析边界（品类定义、地理范围、时间跨度）
2. 收集行业公开数据（研报、上市公司财报、行业协会数据）
3. 估算关键指标（规模、增速、利润率水平）
4. 判断行业生命周期阶段与发展驱动力
5. 输出行业分析摘要

**注意事项：**
- 数据必须标注来源和时间
- 如为估算数据，必须在输出中明确标注「估算」
- 行业定义越窄，分析越有价值——避免泛泛的「大行业」分析

## 小技能一：趋势发现

**职责：** 识别消费趋势、技术趋势、文化趋势的变化方向与影响。

**分析框架：**
- **PEST 框架**：政治（Policy）、经济（Economic）、社会（Social）、技术（Technological）四个维度的趋势扫描
- **STEEP 扩展版**：PEST + 环境（Environmental），适合有可持续性议题的品类
- **信号强弱判断**：区分「已确立的趋势」「新兴趋势」「微弱信号」
- **三值逻辑趋势建模（INC/DEC/CONST）**：当数据不足以做精确预测时，只判方向。趋势不是数值——是方向。对每条趋势给出三值判定：↑ INC（上升）、↓ DEC（下降）、→ CONST（稳定）。无法判断方向时标注 UNCERTAIN。这是为不确定数据设计的量化方式——不做精确数值预测，只做方向性判断，和「不把推测写成发现」的纪律一致

**操作步骤：**
1. 划定趋势扫描范围（与客户品类相关、可能相关的领域）
2. 从四个维度分别收集信号（社媒热点、行业报告、学术研究、政策文件）
3. 评估每条趋势的确定性（高/中/低）和影响程度（高/中/低）
4. 对每条趋势给出三值判定：INC / DEC / CONST / UNCERTAIN——不编数字
5. 聚焦「高确定性 × 高影响」趋势，提出对客户业务的启示
6. 输出趋势报告

**注意事项：**
- 趋势 ≠ 热点。热点短暂，趋势有持续时间
- 每个趋势必须回答「这对客户意味着什么？」——不要只列趋势，不落结论

## 小技能二：竞品分析（三层结构）

**职责：** 对竞品进行生意-产品-传播三层纵深分析。

**本质：** 竞品分析不是搜集信息——是「借别人的经验，解决自己的问题」。别人做了什么不重要，重要的是「这对我到底有什么用」。信息要扣题，分析要本质，结论要落地。

**三大关键动作：定义→拆解→结论。** 先定义分析谁，再拆解对方为何这样做，最后得出可用结论。

**竞品五类型（分析谁）：**

| 类型 | 定义 | 用途 |
|------|------|------|
| **核心竞品** | 同细分市场，产品/定位/人群/投入高度重合 | 最直接参照系，必须深挖 |
| **标杆竞品** | 体量更大、品牌力更强，引领行业趋势 | 学习其在产品定义/品牌建设/营销玩法的长处 |
| **潜力竞品** | 体量不如我们，但某方面打法值得借鉴 | 关注其产品/品牌/营销策略中的亮点 |
| **替代竞品** | 不同细分行业，但解决同一层面需求 | 看消费者实际流失去向 |
| **避坑竞品** | 反面教材——失败案例 | 确定什么不能做，和做什么同等重要 |

**拆解三动作（逐竞品、逐动作）：**

1. **事实层：做了什么？** ——具体动作、时间节奏、资源分配
2. **动机层：为何做？** ——背景（为何在此节点做）、目标（要什么结果）、策略（用什么路径）
3. **效果层：做得如何？** ——拿到了什么结果、成功关键因素、失败核心原因

拆到最后，找到决定项目成败的**根本变量**——这个变量决定了事情的走向。找到了主要矛盾，就找到了本质。

**⚠️ 数据依赖声明：** 生意层和传播层需要第三方数据平台（生意参谋、蝉妈妈、千瓜等）获取定量数据。当前个人开发者阶段，这两个层面的定量数据不可获取——但这不妨碍框架先就位。**现在写进框架，是为了数据到位时知道怎么处理，不回头补。**

### 第一层：生意（Business）

回答：**竞品的生意有多大、钱从哪来、在涨还是在跌？**

| 分析维度 | 核心指标 | 当前阶段可获取？ | 数据来源 |
|---------|---------|:---:|---------|
| **体量** | GMV、sell-in、sell-out、市场份额 | 🔴 不可获取 | 生意参谋/蝉妈妈/魔镜 |
| **组成（渠道）** | 天猫 vs 京东 vs 抖音 vs 线下 各渠道占比 | 🔴 不可获取 | 同上 |
| **组成（产品）** | 各产品线/单品对总营收的贡献占比 | 🔴 不可获取 | 同上 |
| **组成（区域）** | 省/城市层级的销售分布 | 🔴 不可获取 | 同上 |
| **趋势（年度）** | 同比增速、份额变化方向 | 🟡 上市公司财报可获取部分品牌 | 财报 + 第三方平台 |
| **趋势（月度）** | 环比波动、季节性规律、促销节奏 | 🔴 不可获取 | 第三方平台 |

**即使不可获取，也必须做的事：**
- 列出需要什么数据，标注「当前缺失」
- 如果竞品是上市公司，从财报中提取任何提及该品牌/品类的数字
- **绝不能把「没有数据」等同于「生意体量不重要」**

**生意层输出格式（数据到位后）：**

| 天猫渠道占比 | — | — | — | — | — | — |

### 第二层：产品（Product）

回答：**竞品在卖什么、卖多少钱、卖给谁、凭什么和别人不同？**

| 分析维度 | 具体内容 | 当前阶段可获取？ | 数据来源 |
|---------|------|:---:|---------|
| **产品矩阵** | SKU 数量、产品线划分、核心单品 vs 边缘产品 | 🟢 可获取 | 品牌官网 + 电商前台 |
| **产品定价** | 价格带、主力价格段、各渠道定价差异、促销频率与折扣深度 | 🟢 可获取（电商前台） | 淘宝/京东/抖音商城搜索 |
| **人群定位** | 品牌官方宣称的目标人群 vs 实际购买人群 | 🟡 官宣可获取，实际人群不可获取 | 官宣公开；实际人群需第三方平台 |
| **差异化卖点** | 品牌最强调的功能/情感卖点是什么？这是真实的差异还是品类共性？ | 🟢 可获取 | 品牌官网 + 电商详情页 + 社交媒体内容 |

**操作步骤：**
1. 逐竞品拉取电商前台价格（需标注采集日期——价格是时变的）
2. 建立竞品产品矩阵对比表
3. 标注每个竞品的核心差异化主张
4. **校验一必须触发：** 区分「品牌自己说的卖点」vs「消费者在评论里反复提到的购买原因」

**用户问题三分法（痛点/痒点/爽点）：** 分析竞品产品层时，用三分法定位它解决的是哪类问题：

| 类型 | 定义 | 例子 |
|------|------|------|
| **痛点** | 直接困扰用户，不解决不行 | 想喝得爽的汽水又怕胖 |
| **痒点** | 不影响生存，但解决了更舒服 | 新能源车防晒天幕——没有也能开，有了体验更好 |
| **爽点** | 原本没意识到，一旦被满足就回不去 | 丝滑的操作系统——用惯了就回不去 |

判断竞品主打哪类问题，决定「我们该在哪个层面竞争」——用痛点竞争是底线竞争，用爽点竞争是体验竞争，用痒点竞争是差异化机会。

**支撑点（RTB：Reason to Believe）：** 产品价值成立的证明——「凭什么相信你」。五大维度：

| 维度 | 内容 |
|------|------|
| **技术证明** | 专利、实验数据、成分背书 |
| **信任背书** | 权威机构认证、专家推荐、明星代言 |
| **口碑效应** | 用户评价、销量数据、复购率 |
| **设计与细节** | 包装质感、使用体验、细节打磨 |
| **品牌势能** | 品牌历史、行业地位、用户心智 |

**RTB 判别：** 竞品卖点如果找不到支撑点 → 空洞主张，喊了没人信。我们的卖点如果也没有支撑点 → 同样的命运。RTB 是「论点 vs 论据」的关系——卖点是论点，支撑点是论据。

**产品层输出格式：**

| 维度 | 本品 | 竞品A | 竞品B | 竞品C |
|------|------|------|------|------|
| SKU 数 | | | | |
| 价格带 | | | | |
| 主力价格段 | | | | |
| 官宣人群 | | | | |
| 核心卖点 | | | | |
| 是否品类共性？ | | | | |

### 第三层：传播（Communication）

回答：**竞品在哪些渠道、用什么样的内容、花多少钱在传播？消费者怎么谈论它们？**

| 分析维度 | 具体内容 | 当前阶段可获取？ | 数据来源 |
|---------|------|:---:|---------|
| **传播渠道** | 按平台（抖音/小红书/微博/B站/微信）和媒体类型（自有媒体/付费媒体/达人）拆分 | 🟡 方向性可判断，定量不可获取 | 竞品社媒账号 + 第三方平台 |
| **传播声量** | Share of Voice（声量份额）、Share of Spending（投放预算份额） | 🔴 不可获取 | 千瓜/新榜/蝉妈妈 |
| **传播策略** | 核心内容主题、目标人群策略、投放策略（品牌广告 vs 效果广告 vs 达人） | 🟡 内容主题可观察，投放策略不可获取 | 公开社媒内容可看，投放需第三方 |
| **舆情分析** | 正面声量占比、负面声量占比、主要负面话题、舆情趋势变化 | 🟡 单次可手动翻评论，量化不可获取 | 电商评论 + 社媒内容 |
| **搜索策略** | 品类的搜索热词、竞品的搜索占位、本品 vs 竞品的搜索竞争格局 | 🟡 web_fetch 可单次查品类搜索词趋势 | 各平台搜索 + 微信指数/百度指数 |

**操作步骤：**
1. 浏览竞品在主要社媒平台的官方账号（内容主题、发布频率、互动量级）
2. 搜索「竞品名 + 推荐/好用/踩雷」获取消费者的自发讨论方向
3. **如果获取到搜索数据：** 建立品类搜索热词表，对比本品 vs 竞品的搜索占位
4. 标注当前传播分析的定量缺口——「以下为定性方向判断，未获取 SOV/SOS 数据」

**传播层输出格式：**

| 维度 | 本品 | 竞品A | 竞品B | 竞品C |
|------|------|------|------|------|
| 主要社媒平台 | | | | |
| 内容主题方向 | | | | |
| SOV（声量份额） | — | — | — | — |
| 搜索结果占位 | | | | |
| 主要正面话题 | | | | |
| 主要负面话题 | | | | |

### 各层数据可用性总览

| 层 | 个人开发者阶段 | 企业级数据源接入后 |
|------|------|------|
| **生意层** | 🔴 几乎全不可获取——只能做方向性判断，必须标注「以下无定量数据支撑」 | 生意参谋/蝉妈妈/魔镜 → 完整 GMV/share/渠道/趋势 |
| **产品层** | 🟢 官网 + 电商前台可查定价和产品矩阵 | 补充实际购买人群画像 |
| **传播层** | 🟡 内容方向可观察，声量和舆情定量不可获取 | 千瓜/新榜/蝉妈妈 → SOV/SOS + 舆情NLP |

### 三层 vs 旧版六维对比表的关系

旧版的「六维对比表」（定位、产品、价格、渠道、传播、组织）被吸收进三层框架：
- 产品层 = 旧版的产品 + 价格 + 定位
- 传播层 = 旧版的传播 + 渠道
- 生意层 = 旧版完全没有的新维度
- 组织维度 → 保留在「基础信息」中（公司规模、融资等），不单独列层

### 竞争位置总结（必须输出）

在三层分析完成后，用一个段落综合判断品牌在竞争格局中的位置。**不是重复表格——是回答四个问题：**

1. 这个品牌在竞争中处于什么位置？（领导者/挑战者/跟随者/边缘者）
2. 它的核心差异化是什么？这个差异是否可持续？
3. 竞品的共同弱点在哪？品牌有没有机会击穿它？
4. 当前竞争格局中最大的不确定性是什么？（新进入者？技术变革？政策？）

**为什么这一步是必须的：** 三层框架给出了详细的维度和数据，但客户和下游需要的是一个能指导策略的综合判断。数据是手段，定位判断才是目的。

**结论必须导向行动（结论三问）：** 好的竞品分析必须有结论——不是罗列竞品做了什么，是回答三个问题：

1. **借鉴什么？** ——竞品哪些做法值得学，学到什么程度
2. **规避什么？** ——竞品哪些做法是坑，我们绝不能踩
3. **怎么做？** ——基于自身情况，我们接下来具体该做什么

**自检：** 如果看完结论，客户不知道「我们接下来该干什么」——分析不合格。分析只是手段，结论才是目的。

### 护城河分析：Hamilton Helmer Seven Powers

在竞争位置总结之后，对每个核心竞品做护城河耐久性判断。框架使用 Hamilton Helmer 的 Seven Powers——七种结构性竞争优势：

| Power | 含义 | 护城河机制 | 判别问题 |
|------|------|------|------|
| **规模经济** | 规模越大单位成本越低 | 挑战者必须达到同等规模才能匹配单位经济——前期需巨额投入 | "竞品的采购成本或运营效率是否明显优于行业平均？" |
| **网络效应** | 用户越多产品价值越高 | 挑战者从零用户起步——产品天生不如在位者 | "多一个用户是否让所有用户都获益？" |
| **反定位** | 采用在位者无法复制的新商业模式 | 在位者的理性选择是忽视——给挑战者窗口期 | "有没有竞品在以对手不能模仿的方式做生意？" |
| **转换成本** | 用户离开代价高 | 挑战者必须提供超过总转换成本的剩余价值 | "用户换掉这个品牌的实际成本（钱/时间/数据/关系）有多高？" |
| **品牌** | 对客观相似产品产生持续溢价 | 品牌需多年一致信号——无法速成 | "消费者为这个品牌的名字多花了钱吗？不是因为产品更好——就是因为名字？" |
| **独占资源** | 对宝贵资源的优先获取权 | 资源不可复制——挑战者根本拿不到 | "有没有专利/牌照/独家渠道/关键人才是竞品独占的？" |
| **流程优势** | 内嵌的组织流程带来低成本或高品质 | 流程是隐性的、复杂的、长期演化的——不能通过挖人或观察复制 | "竞品有没有做了很多年才磨合出来的内部流程？" |

**操作步骤：**
1. 对每个核心竞品，逐 Power 判断是否持有——必须基于证据，不能凭规模就说"有规模经济"
2. 每个 Power 给定耐久性评级：高（需 3 年以上 + 巨额资本才可能侵蚀） / 中（精明或资金充足的挑战者 1-3 年可侵蚀） / 低（已现裂痕）
3. 识别品类中**所有竞品都不持有的 Power** —— 这些结构空白是潜在的进入机会
4. 结论：“这个品类最大的护城河真空在[Power X]，一个[特征]的进入者可以填补它”

**注意：** 不要给每个品牌都分配「规模经济」和「品牌」——这些是具体结构性优势，不是「公司大就叫规模经济」或「知道名字就叫品牌」。

## 小技能三：信息搜集

**职责：** 系统处理新闻、研报、社媒内容、行业报告等多源信息，提取关键信号。

### 三层信源体系

信息搜集不应是平行的"有就搜"——应按视角分层。每一层回答不同的问题，合在一起形成完整判断。

| 层 | 视角 | 回答 | 典型来源 | 当前可获取性 |
|------|------|------|---------|:---:|
| **第一层：财务与战略** | 品牌自己怎么说、怎么想 | 品牌的规模、增长趋势、战略方向、管理层判断 | 年报、10-K、港交所公告、投资者演示、招股书 | 🟡 上市公司可获取 |
| **第二层：行业与竞争** | 行业怎么走、对手怎么打 | 品类规模、增长率、市场份额、竞品动向 | 行业研报、券商研报、财经媒体、行业分析文章 | 🟡 公开摘要可获取 |
| **第三层：消费者与口碑** | 消费者怎么想、怎么说 | 用户的真实评价、喜欢什么、吐槽什么、怎么买的 | 社媒UGC、电商评价、论坛讨论 | 🟡 可手动翻，不可批量 |

**为什么是三层：** 三层各自独立验证同一个判断。如果财报说"品牌增长强劲"、行业报告说"品类正在萎缩"、消费者说"性价比越来越差"——三者矛盾本身就是最关键的洞察。单层信息看不到这种矛盾。

### 原有信息源分类（保留）

| 类型 | 来源举例 | 用途 |
|------|---------|------|
| 行业研报 | 艾瑞、易观、CBNDATA、券商研报 | 市场规模、格局、趋势 |
| 社媒内容 | 小红书、抖音、微博、B站 | 消费者讨论、品类热度、竞品声量 |
| 新闻资讯 | 36氪、虎嗅、财经媒体 | 竞品动态、行业事件、政策变化 |
| 数据平台 | 生意参谋、千瓜、新榜、蝉妈妈 | 销售数据、内容数据、达人数据 |
| 学术文献 | 知网、Google Scholar | 消费者行为理论、方法论支撑 |

**操作步骤：**
1. 明确信息搜集目标（要回答什么问题？）
2. 选择信息源类型和具体渠道
3. 设定搜索关键词组合
4. 搜集并按可信度排序（一手数据 > 权威报告 > 媒体报道 > 社媒讨论）
5. 提取关键信号，标注来源和可信度
6. 整理成信息简报

**注意事项：**
- 标注每条信息的可信度等级（A=一手数据/B=权威来源/C=媒体引用/D=社媒讨论）
- 区分「描述性信息」和「观点性信息」
- 信息搜集是手段，不是目的——最终要回到「这对客户意味着什么？」

## 强制校验规则

### 校验零：证据来源评级（Evidence Hierarchy）

**核心规则：在分析任何市场数据之前，必须先对数据源本身做可信度评级。行业规模、市场份额、品类增速这些数字——如果来自不同的数据源，可信度差异极大。用了一个不可信的数据源来做竞品分析或市场估算，下游所有判断都建立在虚假的地基上。**

**证据等级体系：**

| 等级 | 来源类型 | 默认权重 | 判断依据 |
|------|---------|---------|---------|
| **E1** | 政府统计、上市公司财报、审计后销售数据 | 0.95 | 有法律效力的公开数据，造假后果严重 |
| **E2** | 专业研究机构（Nielsen、Kantar、Euromonitor、艾瑞、益普索等） | 0.85 | 样本设计规范、方法可审计、误差可计算 |
| **E3** | 客户提供的内部经营数据（CRM、进销存、渠道出货等） | 0.65 | 一般不会故意篡改，但口径可能不一致、覆盖可能不完整 |
| **E4** | 行业媒体、证券研报、公开社媒讨论 | 0.45 | 有参考价值，但可能包含推测、公关包装或选择性报道 |
| **E5** | 客户口述（"我觉得市场大概 50 亿"） | 0.2 | 可以作为方向参考，不能作为市场估算的唯一依据 |

**强制规则：**

1. **所有市场数据输出必须标注证据等级。** 如果市场规模数字来自 E5（客户口述），必须在输出中标注："此数据为客户估计，未经验证，不能作为预算分配的唯一依据。"
2. **E5 级数据不能独立支撑市场判断。** 如果核心市场判断全部依赖 E5——明确告知下游：「以下分析基于客户口述信息，未经过独立核实。在做出重大战略决策前，建议获取 E2 级以上数据源。」
3. **数字看起来精确不等于可信。** "市场 47.3 亿"如果来自客户口述——47.3 这个精度本身是误导性的。标注为"约 50 亿（客户估算）"。
4. **不同来源的数字矛盾时——优先高等级来源，同时标注矛盾。** "E2（尼尔森）显示 30 亿，E4（行业媒体）显示 55 亿——以尼尔森为准，但标注行业媒体的高估值方向。"

### 校验一：区分「品牌宣称」和「消费者实际行为」

**核心原则：** 一个品牌说自己是什么，不等于消费者把它当什么买。

**任何关于「市场空白」的判断，必须经过双重验证：**

| 验证维度 | 问题 | 错误示例 | 正确示例 |
|---------|------|---------|---------|
| 品牌宣称层 | 品牌自己怎么定位？ | 「FILA 定位运动时尚」 | 「FILA 官方描述自己是运动时尚品牌」 |
| 消费者行为层 | 消费者实际用它做什么？ | （未提供） | 「根据电商评论/社媒内容，60% 以上的 FILA 消费者日常穿搭场景购买，非运动场景」 |

**如果消费者行为层无数据，不得宣称「发现市场空白」——只能标注「品牌宣称层面存在定位空白，消费者实际购买行为待验证」。**

### 校验二：竞品范围不遗漏

**核心原则：** 竞品不只是「品牌官方定位相同的品牌」，也包括「消费者实际购买决策中的替代品」。

**竞品名单必须包含两类：**
- 直接竞品：品牌定位相似
- 替代竞品：消费者在同一个决策场景下考虑的其他品类品牌

例：做运动鞋市场分析，不能只看运动品牌——如果消费者买运动鞋是为了日常穿搭，Vans、Converse、甚至 ZARA 基础款鞋都是竞品。

### 校验三：所有分析结论必须标注数据来源和可信度

| 可信度 | 标记 | 示例 |
|--------|------|------|
| A=一手数据 | [A] | 客户提供的销售数据、自有调研 |
| B=权威来源 | [B] | 上市公司财报、权威研报 |
| C=行业估算 | [C] | 基于多个来源交叉推算 |
| D=经验推测 | [D] | 基于行业经验但无直接数据支撑 |

**D 级结论不能作为定位决策的唯一依据。** 如果核心市场判断全部为 D 级，必须明确告知下游：「以下分析基于行业经验推测，需一手调研验证」。

## 小技能四：新产品/新品类扩散预测

**职责：** 判断新产品或新品类上市后，被市场采纳的速度和最终渗透规模。不是所有新产品都以同样速度被接受——有些第一年就饱和，有些要熬十年才被主流接受。

**核心原理（Bass 扩散模型的基础逻辑）：** 新产品的采纳速度由两类人决定：

| 采纳者类型 | 行为驱动力 | 特征 |
|-----------|-----------|------|
| **创新者** | 受外部信息驱动——广告、媒体报道、独立评测 | 自己决定尝试。不需要看到别人先用。占总人口一小部分 |
| **模仿者** | 受他人行为驱动——看到周围人用了才觉得安全 | 需要社会证明才会采纳。占总人口的绝大多数 |

扩散过程的总速度不取决于创新者占总人口的比例——取决于模仿者的占比和模仿速度。一个新品类爆发得有多快，不是看多少人"尝鲜"，是看多少人"在看到别人尝鲜后跟进"。

**两种市场形态：**

| 形态 | 特征 | 策略含义 |
|------|------|---------|
| **创新者主导** | 大量早期的采纳者持续涌入。外部信息是这个市场的主要驱动力 | 早期大预算铺开广告和媒体报道。重心在"让更多人独立获得信息" |
| **模仿者主导** | 早期采纳者少，后续的大波采纳依靠已采纳者影响未采纳者 | 早期不需要大预算。需要一小组高影响力用户先用起来——然后他们的行为会驱动主流跟进。重心在"让早期用户可见" |

**操作步骤：**
1. 判断当前品类处于扩散曲线的哪一段——导入、成长、成熟
2. 判断驱动力来源——当前是创新者驱动还是模仿者驱动
3. 如果品类处于成长早期且模仿者主导：策略不是砸大预算铺广告——是找到并启用一小批有影响力的早期用户，让他们可见
4. 如果品类接近饱和：停止新客获取，转向留存和差异化

**注意事项：**
- 很多品类在早期被烧钱推广强行拉到爆发，然后迅速崩盘——不是扩散成功了，是烧钱买来的创新者在模仿者还没跟进之前就散了
- 扩散预测不是算命——它告诉你"如果当前的条件持续，采纳会以这个速度发展"。如果条件变了（竞品大降价、平台政策剧变），预测需重新做
- 品类之间模仿速度差异巨大——社交产品（可见度高）模仿速度快，私密消费品（牙刷/内衣）模仿速度慢甚至不存在——因为不会有人在社交场合展示这些东西
